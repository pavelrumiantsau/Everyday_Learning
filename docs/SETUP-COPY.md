# Свой бот Everyday Learning — инструкция

Это личный Telegram-бот для изучения языков (литовский с нуля до экзамена A2, испанский, французский): утренние уроки,
карточки, правила, тексты, ИИ-репетитор. У каждого — **своя копия**: свой бот, своя база, свои ключи. Ваш прогресс не
видит никто, и ничего не смешивается с чужим.

- **Время:** ~25 минут, всё в браузере, ничего устанавливать не нужно.
- **Стоимость:** 0 €. Все сервисы — на бесплатных тарифах, банковская карта не нужна.
- **Нужно:** Telegram на телефоне или компьютере и аккаунт на GitHub (если нет — github.com → Sign up).

> Статус (октябрь 2026): пробный запуск. Мастер первой настройки (выбор языков и темпа) и курс литовского с нуля
> появятся в ближайших обновлениях — копия получит их сама (см. «Обновления»).

Всего **8 действий**:

| # | Что сделать | Где | Время |
|---|---|---|---|
| 1 | Создать бота, скопировать токен | Telegram, @BotFather | 3 мин |
| 2 | Создать ключ для ИИ (можно позже) | console.groq.com | 3 мин |
| 3 | Создать токен Cloudflare | dash.cloudflare.com | 7 мин |
| 4 | Сделать свою копию проекта | GitHub | 2 мин |
| 5 | Вставить три ключа | GitHub, ваша копия | 4 мин |
| 6 | Запустить Setup | GitHub | 1 клик + ~5 мин ожидания |
| 7 | Открыть ссылку и нажать Start | Telegram | 1 мин |
| 8 | Ответить на вопросы мастера настройки | Telegram | 2 мин |

Ключи из шагов 1–3 удобно временно вставить в заметку — они понадобятся на шаге 5. После шага 5 заметку удалите.

---

## Шаг 1 — бот в Telegram

1. В Telegram откройте **@BotFather** (с синей галочкой) → **Start** → отправьте `/newbot`.
2. Имя бота — любое, например `Мой литовский`.
3. Username — уникальный, на конце `bot`, например `ivan_lt_learning_bot`.
4. BotFather пришлёт **токен** вида `1234567890:AAH…` — скопируйте его целиком.
   Токен — это пароль от бота. Если он попал не туда: @BotFather → `/revoke`, потом шаг 5 и 6 заново.

## Шаг 2 — ключ для ИИ (Groq, бесплатно, можно пропустить)

Нужен для ИИ-репетитора, проверки письма и голосовых сообщений. Без него всё остальное работает; ключ можно добавить
позже (шаг 5) и снова запустить Setup (шаг 6).

1. Откройте **https://console.groq.com** → войдите через Google или GitHub.
2. Слева **API Keys** → **Create API Key** → имя `everyday-learning` → **Submit**.
3. Скопируйте ключ (начинается с `gsk_`). Он показывается один раз.

## Шаг 3 — токен Cloudflare (бесплатно, без карты)

Cloudflare — это место, где будет работать ваш бот и храниться его база.

1. Зарегистрируйтесь на **https://dash.cloudflare.com/sign-up** и подтвердите e-mail. Сайт или домен добавлять **не нужно** —
   пропускайте всё про домены.
2. Справа вверху значок профиля → **My Profile** → слева **API Tokens** → **Create Token**.
3. Напротив шаблона **Edit Cloudflare Workers** нажмите **Use template**.
4. В разделе **Permissions** нажмите **+ Add more** и добавьте строку: **Account** → **D1** → **Edit**.
5. **Account Resources:** *Include* → ваш аккаунт. **Zone Resources:** оставьте *All zones*.
6. Внизу **Continue to summary** → **Create Token** → скопируйте токен. Он показывается один раз.

## Шаг 4 — своя копия проекта на GitHub

1. Откройте **https://github.com/pavelrumiantsau/Everyday_Learning**.
2. Зелёная кнопка **Use this template** → **Create a new repository**.
3. Repository name — например `everyday-learning`. Выберите **Private** (важно: так ваши настройки и резервные копии видите
   только вы). **Create repository**.

## Шаг 5 — три ключа в вашей копии

В **вашем** новом репозитории: **Settings** → слева **Secrets and variables** → **Actions** → **New repository secret**.
Добавьте по одному (имя — точно как здесь, значение — из заметки):

| Name | Secret |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather (шаг 1) |
| `CLOUDFLARE_API_TOKEN` | токен Cloudflare (шаг 3) |
| `GROQ_API_KEY` | ключ Groq (шаг 2) — если пропустили, не добавляйте |

## Шаг 6 — Setup

1. В вашем репозитории вкладка **Actions**. Если GitHub спрашивает, включить ли workflows, — **I understand… enable them**.
2. Слева **Setup** → справа **Run workflow** → зелёная **Run workflow**.
3. Подождите ~5 минут, пока у запуска не появится зелёная галочка. Если красный крестик — откройте запуск: в разделе
   **Summary** написано, что исправить (обычно — секрет с опечаткой). Исправьте и запустите Setup снова — это безопасно.

## Шаг 7 — привязать бота к себе

1. Откройте зелёный запуск Setup → **Summary**. Там ссылка вида `https://t.me/<ваш_бот>?start=…`.
2. Откройте её на телефоне (или в Telegram на компьютере) → **Start**.
3. Бот поздоровается — теперь он ваш и отвечает **только вам**. Ссылку никому не пересылайте; после привязки она всё равно
   больше не работает.

## Шаг 8 — первая настройка

Бот откроет мастер настройки: какие языки учить (по умолчанию — только литовский), ваш уровень, цель (экзамен A2 и дата),
темп и время утреннего урока. Всё это потом можно поменять командой `/setup` или в ⚙️.

Готово. Первый урок придёт сразу, дальше — каждое утро.

## Обновления

Каждый понедельник копия сама берёт новую версию (новые уроки, исправления), проверяет её и устанавливает. Ваш прогресс и
настройки хранятся в вашей базе и не теряются. Обновить сразу: **Actions → Update → Run workflow**.

### Обновление workflows

Иногда в Summary запуска Update будет написано, что изменились файлы workflows. GitHub не даёт обновлять их автоматически
без отдельного разрешения. Один раз (5 минут):

1. github.com → фото профиля → **Settings** → внизу слева **Developer settings** → **Personal access tokens** →
   **Fine-grained tokens** → **Generate new token**.
2. Name `everyday-learning-update`, Expiration — 1 год, **Repository access:** *Only select repositories* → ваша копия.
3. **Permissions → Repository permissions:** **Contents** → *Read and write*, **Workflows** → *Read and write*.
4. **Generate token** → скопируйте → в вашем репозитории добавьте секрет `WORKFLOWS_TOKEN` (как в шаге 5).
5. **Actions → Update → Run workflow.** Дальше workflows обновляются сами.

## Резервные копии

Каждую ночь база копируется в ветку `backup` вашего репозитория (только для вас, репозиторий приватный). Восстановить
можно любой день из истории этой ветки — напишите владельцу проекта, он поможет.

## Если что-то пошло не так

| Что видно | Что сделать |
|---|---|
| Setup: «Не хватает секретов» | шаг 5: проверьте имена секретов (заглавные буквы, подчёркивания) |
| Setup: «CLOUDFLARE_API_TOKEN не принят» | шаг 3 заново, обновите секрет (Settings → Secrets → карандаш), Setup снова |
| Setup: «Нет доступа к базам D1» | токену не хватает строки *Account → D1 → Edit* (шаг 3, пункт 4) |
| Setup: «Не удалось зарегистрировать адрес workers.dev» | откройте dash.cloudflare.com → **Workers & Pages**, выберите адрес, Setup снова |
| Бот пишет «Этот бот ещё не привязан» | откройте ссылку из **Summary** последнего запуска Setup (шаг 7) |
| Бот привязался не к тому аккаунту | **Actions → Setup → Run workflow**, отметьте «Отвязать бота…», затем новая ссылка из Summary |
| ИИ не отвечает | добавьте или обновите `GROQ_API_KEY` (шаг 2 и 5), Setup снова |

## Удалить всё

Удалите репозиторий (Settings → внизу **Delete this repository**), в Cloudflare: **Workers & Pages** → `everyday-learning`
→ Settings → Delete, и **D1** → `everyday-learning` → Delete; бота — @BotFather → `/deletebot`.
